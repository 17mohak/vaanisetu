      How it works on AWS
      
      
      
        
      01
      Upload
      The browser gets a pre-signed URL from API Gateway → Lambda and uploads the photo straight to a private S3 bucket.
      
        
      02
      Verify
      Amazon Rekognition checks the photo really contains printed text before any AI cost is spent.
      
        
      03
      Understand
      Amazon Nova on Bedrock transcribes the page, works out what it means and writes a plain explanation in your language.
      
        
      04
      Speak
      Amazon Polly neural voices turn the explanation into natural speech, stored in S3 and logged in DynamoDB.
